# ASK FDM — Evaluation Scripts

Evaluation scripts for **Frequency-Multiplexed In-Context Memory Encoding for Language Models** 

Models available at [prompterminal/](https://huggingface.co/prompterminal) on HuggingFace.

---

## Requirements

```bash
pip install torch transformers numpy tqdm
```

All scripts assume a CUDA GPU. Models run in `bfloat16` except GPT-2 (float32).

---

## Scripts by Experiment

### 1. Joint Retrieval Accuracy (Table 5)
`joint_retrieval/joint_accuracy_multi.py`

Measures fraction of samples where all N extra channels (ch8–39) are decoded correctly simultaneously, for N ∈ {1,2,4,8,16,24,32}.

```bash
python joint_accuracy_multi.py gpt2
python joint_accuracy_multi.py qwen3
python joint_accuracy_multi.py lfm2
python joint_accuracy_multi.py hermes3
```

Models and test data paths are configured in `MODEL_CONFIGS` at the top of the script. Update `default_model_dir` to point to your local model checkpoint and `test_data` to the matching stage 4 test file. Each model must use test data generated by its own encoder (vocabulary-specific token mapping).

---

### 2. Frequency Gradient (Table 6)
`frequency_gradient/hermes3_perchannel_eval.py`

Per-channel retrieval accuracy for Hermes3 across all 40 carrier frequency bands.

```bash
python hermes3_perchannel_eval.py
```

Update `MODEL_PATH` and `TEST_DATA` at the top of the script to point to your Hermes3 checkpoint and test data.

For GPT-2, Qwen3, and LFM2.5, per-channel accuracy is computed as a byproduct of `joint_accuracy_multi.py` and printed to stdout.

---

### 3. Signal Corruption / Mechanistic Validation (Table 8)
`signal_corruption/fdm_corruption_ptgt.py`

Adds Gaussian noise to FDM signal token embeddings at σ ∈ {0, 0.5, 1, 2, 3, 5, 10, 20} and measures P(tgt) — the softmax probability assigned to the first token of the correct answer.

```bash
python fdm_corruption_ptgt.py --model qwen3
python fdm_corruption_ptgt.py --model lfm2
python fdm_corruption_ptgt.py --model hermes3
```

Update model paths in the script config. GPT-2 uses action accuracy (generate + keyword match) from a separate run.

---

### 4. N-Hop Composition (Table 7)
`nhop_composition/nhop_training_multi.py`

Generates hop-controlled composition data, fine-tunes an nhop stage on top of the base FDM model, and evaluates decision accuracy and extra-channel accuracy across 1–5 hops.

```bash
# Generate data
python nhop_training_multi.py generate gpt2
python nhop_training_multi.py generate qwen3
python nhop_training_multi.py generate lfm2
python nhop_training_multi.py generate hermes3

# Train
python nhop_training_multi.py train gpt2
python nhop_training_multi.py train qwen3
python nhop_training_multi.py train lfm2
python nhop_training_multi.py train hermes3

# Evaluate
python nhop_training_multi.py eval gpt2
python nhop_training_multi.py eval qwen3
python nhop_training_multi.py eval lfm2
python nhop_training_multi.py eval hermes3
```

Base model paths are set in `MODEL_CONFIGS` at the top of the script.

---

### 5. Channel Density Scaling (Table 3)
`channel_density/channel_density_scaling_multi.py`

Tests 10, 20, and 40 channel configurations at fixed 20K training budget across GPT-2 and Qwen3, measuring how per-channel accuracy scales with spectral crowding.

```bash
python channel_density_scaling_multi.py
```

---

### 6. Cross-Length Transfer (Table 4)
`cross_length_transfer/cross_eval_diagonal.py`

Evaluates 512-token trained models on 1024-token test data and vice versa, without retraining.

```bash
python cross_eval_diagonal.py
```

Update model paths and test data paths in the script for each direction of the transfer matrix.

---

## Hardware

All experiments run on a single NVIDIA RTX 5090 (32GB VRAM). Blackwell GPUs require `bfloat16` — do not use `float16`.

---

## Notes

- Each model uses a vocabulary-specific token mapping (seed=42, drawn from `[0, |V|)`). Test data must be generated by the same encoder used during training.
- The FDM signal is 512 tokens (256 samples × 2 encoders with S-random interleaving). 1024-token experiments use 512 samples per encoder.

## Models

Download fine-tuned FDM models from HuggingFace before running any scripts:

```bash
from huggingface_hub import snapshot_download

snapshot_download("prompterminal/fdm_40ch_turbo_v3_model_final")  # GPT-2
snapshot_download("prompterminal/fdm-40ch-turbo-v3-qwen3")        # Qwen3
snapshot_download("prompterminal/fdm-40ch-turbo-v3-lfm2")         # LFM2.5
snapshot_download("prompterminal/fdm-40ch-hermes3-3b")            # Hermes3
```


Update `default_model_dir` in each script's `MODEL_CONFIGS` to point to the downloaded model directory.
